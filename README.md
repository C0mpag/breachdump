# breachdump
Breach Dump allows you to search through publicly breached databases to ensure your data hasn't been compromised.

## Snake Game
A basic version of the classic Snake game is provided in `snake.py`. It uses the built-in `curses` library.

### Running
Execute the game with Python 3:

```bash
python3 snake.py
```

Use the arrow keys to control the snake. Eat the `*` characters to grow longer and avoid colliding with the walls or yourself.
